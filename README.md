# CI/CD Pipeline Generator

**Автономный скрипт для генерации CI/CD-пайплайнов «из коробки»**

Сервис, который по ссылке на репозиторий автоматически анализирует структуру проекта и генерирует готовый шаблон пайплайна для **Jenkins** или **GitLab CI** — сокращая время подготовки CI/CD-конвейера с часов до минут.

---

## 🎯 Суть проекта

MVP-сервис, который:

1. **Анализирует** репозиторий по ссылке — структуру директорий, файлы конфигурации, исходный код.
2. **Определяет** технологии: языки, фреймворки, зависимости, менеджеры пакетов.
3. **Генерирует** персонализированный шаблон пайплайна для Jenkins или GitLab.
4. **Обеспечивает** сборку, тестирование и деплой «из коробки».

---

## 🎯 Глобальные технические цели

К концу работы должны быть достигнуты:

- **Анализ репозиториев** — реализованы алгоритмы распознавания стека для целевых комбинаций технологий: Java/Maven, TypeScript/npm, Python/pip.
- **Библиотека адаптивных шаблонов** — генерация конфигураций для Jenkins и GitLab CI под разные стеки.
- **Рабочий сервис** — Spring Boot-приложение с REST API, развёрнутое на публичном хостинге.
- **UI** — ввод ссылки на репозиторий и наглядный вывод результата анализа и сгенерированного пайплайна.
- **Обработка граничных случаев** — некорректные ссылки, пустые/неподдерживаемые репозитории.
- **Документация** — README с локальным запуском и описание API.
